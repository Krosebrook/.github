# Krosebrook default community health files

Public governance defaults inherited automatically across `Krosebrook/*` repositories that do not define their own local overrides.

## Inherited files

| File | Scope |
| --- | --- |
| [`SECURITY.md`](SECURITY.md) | Coordinated private vulnerability reporting policy and supply-chain baseline |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Checkpoint-driven pull request and verification expectations |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant v2.1 behavioral standards |
| [`SUPPORT.md`](SUPPORT.md) | Documentation lookup, issue triage routing, and security boundary |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request verification checklist |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/config.yml) | Structured YAML Issue Forms (`bug_report.yml`, `feature_request.yml`) |
