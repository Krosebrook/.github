# Support

## Finding help

1. Read the repository `README.md`, `CHANGELOG.md`, and `docs/` directory first for install commands and runtime flags.
2. Search existing open and closed GitHub Issues in the target repository before opening a new thread.
3. Open a structured `Bug report` or `Feature request` using the repository YAML Issue Forms, including your OS, runtime version (`node -v`, `python3 --version`), and exact error output.

## Security disclosures

Never post sensitive exploit details or credentials in public support issues. Follow [`SECURITY.md`](SECURITY.md) for private disclosure instructions.
